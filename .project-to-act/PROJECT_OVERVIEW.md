## 项目目标

- 用 AI 对话让不懂代码的企业用户生成/修改官网（选模板、改文案、传商品、发布）
- 本期目标：让"AI 对话不蠢"——改得准、记得住、写得好、不误删

## 范围

### 包含

- AI 对话改造：模板切换语序、多轮记忆（服务端 session）、文案简短约束
- 语言 conformance（只改点名语言）、商品索引截断、破坏性操作确认
- 超时有限重试、模型自评（做轻）、会话记忆可观测

### 非目标

- 图片上传（用户明确本期不做）
- 多站点、鉴权、独立发布、询盘接线（backlog）
- 两阶段调用、精准上下文窗口（评估为过度设计）

## 技术路线与关键约束

- Next.js 16 + React 19 + Zod 4 + DeepSeek（deepseek-v4-flash）
- 生产模式 + PostgreSQL；dev 模式有 Turbopack EPERM 环境 bug（用 npm run build && npm run start）
- 测试：node --test --experimental-strip-types，被测模块只用相对导入（不解析 @/）
- 8 种结构化操作 schema 不变；SSE 事件结构不变（仅加字段）；旧客户端零回归
