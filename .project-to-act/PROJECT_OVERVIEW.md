## 项目目标

- 核心：用户用自然语言一句话描述业务，AI 理解意图 → 匹配真实开源模板 → 生成整站初稿 → 工作台精修。
- 当前迭代目标：模板推荐必须覆盖全部 22 个真实开源模板（本地快照），修复"推荐总推 4 个默认骨架/追问轮推荐丢失"问题。

## 范围

### 包含

- 22 个开源模板库（vendor 子模块，全部构建本地快照，preview 永久稳定）
- 一句话意图理解（行业/受众/语气/色系/板块）+ 模板匹配
- 生成确认页（推荐模板 + 跨分类下拉 + 风格选择器）
- 工作台 / 发布页渲染真实开源模板 iframe

### 非目标

- 不做纯从零生成（Bolt 路线）——只做模板结构 + AI 内容填充
- 不做任意 HTML/CSS 自由生成——只走白名单结构化操作 + design tokens

## 技术路线与关键约束

- 技术栈：Next.js App Router + TypeScript + zod + SSE + node:test
- 模板渲染：`OpenSourceTemplateFrame` iframe 加载真实开源模板本地快照；`SiteRenderer` 仅兜底
- 模板匹配：LLM 产出 `recommendedTemplateId` → `resolveTemplate`（关键词定 category → 白名单校验 → 默认兜底）
- 设计变量：12 色板 design tokens，风格选择器覆盖 intent 并随生成持久化
- 网络约束：npm 装依赖走国内镜像（registry.npmmirror.com）；上游 demo 不可达时靠本地快照

## 数据与安全边界

- 数据分类：站点草稿（本地存储）、生成记录（API 存证）
- 敏感信息处理：只记录脱敏摘要、证据 ID 和受控位置，不粘贴原始敏感数据。管理文档不存密钥（DeepSeek API Key 在 .env.local，已 gitignore）。
